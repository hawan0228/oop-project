# Dino Run

物件導向程式設之期末專題，以 C++ 與 SDL2 開發 2D 的跑酷遊戲。透過 `Player`、`Coin` 與 `Scoreboard` 類別，分別封裝角色行為、金幣狀態與計分功能，實作物件導向的 class 設計與分工。

## 規則與描述

- 地面、金幣與障礙物持續捲動，遊戲速度逐漸增加。
- 跳躍包含重力與落地判定，角色落地後才能再次起跳。
- 兩種金幣分別加 5 分與 10 分，金幣及道具會循環出現。
- 撞到障礙物後結束遊戲，可重新開始；切換到其他視窗時自動暫停。

## 操作方式

| 按鍵 | 操作 |
| --- | --- |
| 空白鍵／↑ | 開始遊戲、跳躍 |
| ←／→ | 左右移動 |
| R | 遊戲結束後重新開始 |
| Esc／視窗關閉按鈕 | 離開遊戲 |

道具碰到即可取得，不需要額外按鍵。

| 道具 | 效果 |
| --- | --- |
| 藍色 S：護盾 | 抵擋一次仙人掌碰撞，使用後消耗 |
| 紅色 M：磁鐵 | 持續 6 秒，自動收集附近金幣 |

## 程式架構

- [game.cpp](game/game.cpp)：遊戲主迴圈、場景捲動、障礙、道具與遊戲狀態。
- [Player](game/player.h)：角色移動、跳躍、動畫與碰撞判定。
- [Coin](game/coin.h)：金幣移動、浮動、收集與重設。
- [Scoreboard](game/scoreboard.h)：分數管理與顯示。

## 開發環境

使用 C++17、SDL2、SDL2_image 與 SDL2_ttf。建置前需依本機環境設定標頭檔、函式庫路徑及連結選項；執行時需將 `game/asset` 與 `game/font` 複製為執行檔同一目錄下的 `asset` 與 `font` 資料夾。
